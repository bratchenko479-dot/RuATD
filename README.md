# RuATD Text Detection

This repository contains the final project for the NLP course, Spring 2026.

## Task

The task is to detect whether a Russian text was written by a human or generated by a machine.

This is a binary classification task:

- `0` — human-written text
- `1` — machine-generated text

## Dataset

The project uses the RuATD 2022 dataset for Russian artificial text detection.

The original dataset contains labels:

- `H` — human-written text
- `M` — machine-generated text

In this project, the labels are converted as follows:

- `H` → `0`
- `M` → `1`

The original test file does not contain labels, so the validation set is used as the evaluation set in this project.

Raw data files are not stored in this repository. They should be placed into:

```text
data/raw/
```

Expected raw files:

```text
data/raw/train.csv
data/raw/val.csv
data/raw/test-2.csv
```

After preprocessing, the processed files are created in:

```text
data/processed/
```

## Models

The following models are compared:

1. Majority baseline
2. Word TF-IDF + Logistic Regression
3. Word TF-IDF + Linear SVM
4. Char TF-IDF + Logistic Regression
5. Char TF-IDF + Linear SVM
6. Word+Char TF-IDF + Logistic Regression
7. RuBERT-tiny2

RuBERT-tiny2 was fine-tuned on a 10,000-example subset of the training data for 1 epoch due to computational limitations.


## Results

| Model | Accuracy | Macro Precision | Macro Recall | Macro F1 |
|---|---:|---:|---:|---:|
| Word+Char TF-IDF + Logistic Regression | 0.7036 | 0.7036 | 0.7036 | 0.7036 |
| Char TF-IDF + Logistic Regression | 0.6976 | 0.6976 | 0.6976 | 0.6976 |
| Char TF-IDF + Linear SVM | 0.6923 | 0.6923 | 0.6923 | 0.6923 |
| Word TF-IDF + Logistic Regression | 0.6723 | 0.6724 | 0.6723 | 0.6723 |
| Word TF-IDF + Linear SVM | 0.6634 | 0.6634 | 0.6634 | 0.6634 |
| RuBERT-tiny2 | 0.6294 | 0.6298 | 0.6294 | 0.6291 |
| Majority baseline | 0.5000 | 0.2500 | 0.5000 | 0.3333 |

The best model in this experiment is Word+Char TF-IDF + Logistic Regression.


Install dependencies:

```bash
pip install -r requirements.txt
```

## How to Run

### 1. Prepare data

```bash
python src/prepare_data.py
```

This script reads the raw RuATD files from `data/raw/`, converts labels, and saves processed files to `data/processed/`.

### 2. Train baseline models

```bash
python src/train_baselines.py
```

This script trains:

- Majority baseline
- TF-IDF + Logistic Regression
- TF-IDF + Linear SVM

The results are saved to:

```text
results/results_baselines.csv
```

### 3. Train RuBERT-tiny2

```bash
python src/train_rubert.py
```

This script fine-tunes RuBERT-tiny2 for binary classification.

The results are saved to:

```text
results/results_rubert.csv
```

### 4. Collect final results

```bash
python src/collect_results.py
```

This script combines all results into:

```text
results/results.csv
```

### 5. Error Analysis

For the best model, Word+Char TF-IDF + Logistic Regression, we saved predictions and inspected classification errors.

| Error type | Count |
|---|---:|
| Total errors | 6,376 |
| False positives | 3,213 |
| False negatives | 3,163 |

False positives are human-written texts classified as machine-generated. Many of them have formal, bureaucratic, or news-like style.

False negatives are machine-generated texts classified as human-written. Many of them are short, fluent, or written in a historical or encyclopedic style.
### 6. Create plots

```bash
python src/make_plots.py
```

This script creates plots and saves them to:

```text
results/figures/
```
